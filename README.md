# Cylindrical Paper Bobbin Fresco Print Defect Dataset

## 📄 Abstract
In industrial production lines, especially in the textile and packaging sectors, quality control of cylindrical objects presents unique challenges due to geometric distortions and specular reflections. This dataset was created to address the problem of detecting fresco print defects on cylindrical paper bobbins used in yarn winding technologies.

The dataset consists of original images captured from a real production line. To overcome the class imbalance problem common in industrial scenarios, data augmentation techniques (rotation, brightness adjustment, flipping) were applied. This dataset serves as a benchmark for evaluating deep learning models, particularly lightweight CNN architectures like MobileNetV2, on cylindrical surfaces.

## 📊 Dataset Properties
The dataset is categorized into two main classes: **Defective** and **Normal**.

* **Total Images:** 3,100 (after augmentation)
* **Original Data:** 1,900 Images
* **Image Format:** .jpg / .png
* **Resolution:** Resized to 224x224 pixels for CNN inputs.

### Class Distribution
| Class Name | Description | Number of Images |
| :--- | :--- | :--- |
| **Defective** | Bobbins with print errors (color shift, missing print, etc.) | 1,800 |
| **Normal** | Defect-free bobbins | 1,300 |
| **Total** | **Dataset Size** | **3,100** |
